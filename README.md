## 📦 Installation (For Developers)

Want to run this project locally? Follow these steps:

```bash
git clone https://github.com/shammarianas/Sham-Marianas.git
cd shammarianas
npm install
npm run dev

npm install @stripe/stripe-js @stripe/react-stripe-js


for 3d model preview
npm install three
npm install three @react-three/fiber@8.15.10 @react-three/drei@9.85.0
```

Check Firebase.js
Use the right api configuration 


npm install pdfmake, pdfmake@0.2.12

npm i react-helmet
npm install react-lazy-load-image-component
